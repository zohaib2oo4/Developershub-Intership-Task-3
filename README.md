## Task 3: Customer Churn Prediction (Bank Customers)

**Objective:**  
Identify customers likely to leave the bank (churn).

**Approach:**  
- Cleaned and prepared the dataset, handling categorical variables using label encoding and one-hot encoding.  
- Trained a classification model (Decision Tree / Logistic Regression).  
- Analyzed feature importance to understand drivers of churn.

**Results & Insights:**  
- Model successfully identified high-risk churn customers with reasonable accuracy.  
- Features like account balance, tenure, and geography significantly influenced churn.  
- Visualization of feature importance helped identify key retention strategies for the bank.
